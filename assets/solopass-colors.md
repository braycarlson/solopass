# solopass colors

The gradient on the circle runs from its top left corner to its bottom right corner, and each stop is listed with its offset.

| Use | Stops |
|---|---|
| Circle | `#7940E7` at 0, `#0564E3` at 1 |

| Use | Color |
|---|---|
| Symbol | `#FFFFFF` |
| Wordmark on dark | `#FFFFFF` |
| Wordmark on light | `#0A0A0A` |

## Tray

The tray draws the same symbol on a flat circle whose color follows the state of the connection.

| State | Color |
|---|---|
| Busy | `#F59E0B` |
| Connected | `#10B981` |
| Disconnected | `#71717A` |

## Mono

A mono file without a ground fills each shape with `currentColor`, so an inline copy takes the color of the text around it. The mono mark cuts the symbol out of its circle, so the ground shows through the symbol.
